# 10 — 综合智能门禁系统

## 项目目标

综合使用 RFID、显示屏、矩阵键盘、舵机或其他执行器以及 STM32 控制逻辑，完成一个具有实际产品雏形的嵌入式智能门禁系统。

## 计划功能

- RFID 卡片身份认证
- 密码 / 矩阵键盘认证
- TFT / OLED 状态显示
- 舵机或电子锁执行机构
- 访问记录
- 蜂鸣器与状态指示
- 模块化驱动程序
- 多种认证方式的逻辑管理
- 异常情况与错误提示

## 系统目标

这是本仓库第一个较完整的系统级综合项目，将前面学习的多种通信总线、外设驱动和控制逻辑整合到一个具有明确功能的嵌入式产品中。

## 预计涉及技术

- GPIO
- 定时器 / PWM
- SPI
- I²C
- UART
- RFID
- 显示界面
- 按键输入
- 舵机控制
- 状态机
- 模块化软件设计
