# 06 — 7 寸 TFT LCD 图形界面

## 项目目标

使用已经购入的 **7 寸 TFT LCD 液晶显示模块**，从基础液晶驱动逐步学习大尺寸显示、图形绘制、人机交互和嵌入式图形界面设计。

该项目后续将作为综合嵌入式系统的主要显示与交互平台。

## 当前硬件

- STM32F103ZET6 精英开发板
- 7 寸 TFT LCD 液晶显示模块
- 面包板及连接线

## 学习内容

- 确认 TFT LCD 实际接口类型与控制器
- 根据接口选择 STM32 驱动方案
- 液晶初始化流程
- 基础颜色与像素控制
- 字库与中文/英文文字显示
- 点、线、矩形、圆形等基础图形绘制
- 图片显示
- 触摸功能（屏幕硬件支持时）
- 界面布局与页面切换
- 数据显示与简单控件
- 局部刷新与刷新效率优化
- 驱动代码模块化

## 项目阶段

### 第一阶段：屏幕点亮

目标：完成 STM32 与 7 寸 TFT LCD 的硬件连接，确认供电、接口和通信方式，并成功显示纯色画面。

### 第二阶段：图形与文字

目标：实现像素、基本图形、文字、图片等基础显示功能。

### 第三阶段：图形界面

目标：设计菜单、状态栏、按钮、数据区域等基础 UI。

### 第四阶段：触摸交互

如果屏幕带触摸功能，将进一步实现触摸坐标读取、按键/按钮响应和页面交互。

### 第五阶段：综合应用

将 TFT LCD 接入后续综合项目，例如：

- 智能门禁系统
- 环境监测终端
- MPU6050 姿态数据显示
- ESP8266 网络数据终端
- 参数配置与设备状态管理

## 注意事项

在正式编写驱动之前，需要根据实际购买的屏幕型号确认：

1. 屏幕控制器型号
2. 接口类型（例如 SPI、8080 并口或 RGB）
3. 分辨率
4. 逻辑电平要求
5. 背光供电方式
6. 触摸控制器型号及接口
7. STM32F103ZET6 的 GPIO 资源占用

确认以上信息后再确定最终接线和驱动程序，避免错误接线造成硬件损坏。
